## О репозитории

Это не портфолио. Это **живой дневник обучения**. Здесь лежит код, который я пишу сам — от простых задач на циклы до проектов с состоянием, файлами и игровым циклом.

Цель — не «показать красивый код», а **зафиксировать путь**. Каждая задача, каждый проект, каждая ошибка — часть процесса. Долгосрочная цель — геймдев и Unreal Engine 5.

## Проекты

### FightingArena
Консольный симулятор пошагового боя. Демонстрация ООП: наследование, полиморфизм, абстрактные классы, инкапсуляция, передача объектов по ссылке, рандом с критами.

**Стек:** C++  
**Что изучил:** `class`, `virtual`, `override`, `private`, передача объектов по ссылке (`Character&`), `rand()`, игровой цикл.  
**Папка:** [`FightingArena/`](./FightingArena)

---

### GuildSystem
Система управления гильдией. Демонстрация работы с вектором указателей на абстрактный класс, полиморфизм и алгоритм поиска сильнейшего участника.

**Стек:** C++  
**Что изучил:** `vector<GuildMember*>`, полиморфизм, поиск максимума по характеристике через `->`, работа с абстрактными классами.  
**Папка:** [`GuildSystem/`](./GuildSystem)

---

### InventorySystem
Консольный инвентарь. Последняя версия использует `std::map` для хранения предметов, что позволяет мгновенно находить их по названию.

**Стек:** C++  
**Что изучил:** `std::map`, интеграция мапы с ООП, итераторы, `find()` и безопасный поиск, рефакторинг с `vector` на `map`.  
**Папка:** [`InventorySystem/`](./InventorySystem)

### Quiz

**Папка:** [`Quiz/`](./Quiz)

## Прогресс обучения

### Пройденные темы

- **Циклы:** `for`, `while`, `do-while`, вложенные циклы.
- **Условия:** `if / else if / else`, `switch`, порядок проверок.
- **Функции:** параметры, возврат, `void`, `bool`, ссылки (`int&`), декомпозиция.
- **Массивы:** базовые операции.
- **Строки:** базовые операции, обработка текста (`tolower`, `.find()`, `.length()`).
- **Структуры:** `struct` (объявление, поля, использование в векторах).
- **Контейнеры:** `std::vector` (`push_back`, `size`, перебор, `range-based for`).
- **Контейнеры:** `std::map` (ключ-значение, `find`, итераторы, автоматическая сортировка).
- **ООП (Классы):** `class`, `private`/`public`/`protected`, конструкторы, инкапсуляция.
- **ООП (Наследование):** базовые и производные классы, `virtual`, `override`, вызов конструктора родителя.
- **ООП (Полиморфизм):** абстрактные классы (`= 0`), векторы указателей, передача объектов по ссылке.
- **Файлы:** чтение и запись (`ofstream`, `ifstream`).
- **Игровая логика:** игровой цикл, состояние, рестарт.
- **Git и GitHub:** базово.
