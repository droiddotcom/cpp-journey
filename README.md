# cpp-journey

> Мой путь в C++ с нуля. Учебные проекты, от калькулятора до игр.

---

## 📁 Проекты

### 🧮 Kalkulator1
Консольный калькулятор с меню и защитой от ошибок ввода.

**Изучено:** `switch/case`, `cin.fail`, `cin.clear`, `cin.ignore`, функции, ссылки (`&`)

---

### 🎲 GuessANumber
Игра «Угадай число». Компьютер загадывает — игрок угадывает.

**Изучено:** `rand()`, `srand()`, циклы, вложенные циклы, `break`

---

### 📋 TodoList
Консольный список задач с сохранением в файл.

**Изучено:** `struct`, `vector`, `fstream`, `find`, `substr`, `erase`, `sort` с лямбдой, цветной вывод, `SetConsoleTextAttribute`

**Возможности:**
- ➕ Добавить задачу
- 👀 Показать все
- ✅ Сменить статус
- ✏️ Редактировать
- 🗑️ Удалить
- 🧹 Очистить всё
- 💾 Сохранение/загрузка из файла
- 📊 Счётчик и сортировка

---

### 📄 FileTest
Запись и чтение файла.

**Изучено:** `ofstream`, `ifstream`, `getline` с файлом, `is_open()`

---

### ❌⭕ TicTacToe
Крестики-нолики для двух игроков.

**Изучено:** двумерные массивы (`char board[3][3]`), игровое состояние, проверка 8 комбинаций победы, счётчик ходов, ничья

**Возможности:**
- 🎮 Два игрока по очереди
- 🚫 Проверка занятой клетки
- 📍 Проверка координат
- 🏆 Определение победы
- 🤝 Определение ничьей
