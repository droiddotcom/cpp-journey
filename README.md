\# cpp-journey



Мой путь в C++ с нуля. Здесь учебные проекты.



\## Проекты



\### Kalkulator1

Консольный калькулятор с меню.



\*\*Учит:\*\* switch/case, обработка ошибок ввода (`cin.fail`, `cin.clear`, `cin.ignore`), функции, ссылки (`\&`), защита от деления на ноль.



\### GuessANumber

Игра «Угадай число». Компьютер загадывает — игрок угадывает.



\*\*Учит:\*\* `rand()`, `srand()`, циклы, вложенные циклы, `while` с условием и `break`.



\### TodoList

Консольный список задач с сохранением в файл.



\*\*Учит:\*\* `struct`, `vector`, `fstream` (запись/чтение), `find`, `substr`, `erase`, `sort` с лямбдой, `SetConsoleTextAttribute` для цветного вывода, работа с пользователем (подтверждения, проверки).



\*\*Что умеет:\*\*

\- Добавить задачу

\- Показать все задачи

\- Сменить статус (выполнено/не выполнено)

\- Удалить задачу

\- Очистить всё

\- Редактировать задачу

\- Сохраняет и загружает задачи из файла

\- Цветной вывод, счётчик, сортировка



\### FileTest

Запись и чтение файла.



\*\*Учит:\*\* `ofstream`, `ifstream`, `getline` с файлом, проверка `is\_open()`.



\### TicTacToe

Крестики-нолики для двух игроков.



\*\*Учит:\*\* двумерные массивы (`char board\[3]\[3]`), игровое состояние (`current`), проверка победы по 8 комбинациям, счётчик ходов, ничья.



\*\*Что умеет:\*\*

\- Два игрока ходят по очереди

\- Проверка занятой клетки

\- Проверка координат

\- Определение победы

\- Определение ничьей
