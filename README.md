- 💾 Сохранение/загрузка из файла
- 📊 Счётчик и сортировка

### ❌⭕ [tic-tac-toe](./tic-tac-toe)
Крестики-нолики для двух игроков.

**Изучено:** двумерные массивы (`char board[3][3]`), игровое состояние, проверка 8 комбинаций победы, счётчик ходов

**Возможности:**
- 🎮 Два игрока по очереди
- 🚫 Проверка занятой клетки
- 📍 Проверка координат
- 🏆 Определение победы
- 🤝 Определение ничьей
